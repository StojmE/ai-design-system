# UX copy rules

Words are part of the interface. These rules keep them consistent with the brand: clear, calm, trustworthy, capable and human.

## Basics

- **Sentence case everywhere:** "New chat", "Rename conversation". Proper nouns keep their capitals.
- **Plain words.** "Use", not "utilize". "Start", not "initiate". Avoid jargon like "LLM", "tokens" or "inference" in UI unless the audience needs them.
- **Short.** Labels 1–3 words; descriptions one sentence; errors two short sentences at most.
- **Address the user as "you".** The product speaks as "we" only in legal or account contexts. The AI speaks as "I" in its own replies, never in UI chrome.
- **No exclamation marks** in UI chrome. **No emoji** in components.
- **Numbers as numerals:** "3 messages left", not "three".

## Buttons and links

- Start with a verb that names the outcome: "Generate summary", "Create project", "Delete chat".
- The confirm button in a dialog repeats the action from the title: title "Delete conversation?" → button "Delete".
- Avoid "OK", "Yes", "Submit", "Click here".
- Links describe where they go: "Read the usage guide", not "Learn more" on its own.

## The AI's voice in UI

| Moment | Write | Avoid |
|---|---|---|
| Thinking | "Thinking…" then "Thought for 12 seconds" | "Processing your request" |
| Searching | "Searching the web…" | "Accessing the internet" |
| Unsure | "I couldn't find this in your files." | "Error: no results" |
| Disclaimer | "AI can make mistakes. Check important info." | "This AI is 100% accurate" |
| Actions it takes | "Created a draft" | "I have successfully generated…" |

## Formatting

| Item | Rule | Example |
|---|---|---|
| Ellipsis | Use "…" for ongoing states and for menu items that open more input | "Uploading…", "Rename…" |
| Dates | Relative for recent, absolute after a week | "09:41", "Tue", "Nov 3" |
| Times | 24-hour or locale default; no seconds | "09:41" |
| Sizes | Number + unit with a space | "2.4 MB" |
| Lists in sentences | No serial comma | "PDF, DOCX or TXT" |
| Quotation marks | Curly quotes and apostrophes | “Draft”, don’t |

## Word list

| Use | Not |
|---|---|
| Chat | Conversation thread, session |
| Project | Workspace, folder (unless it is a folder) |
| Model | Engine, brain |
| Sign in / Sign out | Log in, login (as a verb) |
| Delete | Remove (when it's permanent) |
| Remove | Delete (when it can be added back) |
| Upgrade | Buy, purchase |
